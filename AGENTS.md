# Ramas del repositorio

Las ramas autorizadas, tanto localmente como en GitHub, son `main`, `MVP1` y `MVP2`.

- Usa `MVP2` para el trabajo habitual y conserva `MVP1` como histórico.
- Usa `main` para producción y sigue el flujo de revisión de [DEPLOYMENT.md](DEPLOYMENT.md).
- Para aislar cambios o hacer pruebas en paralelo, usa un worktree con `HEAD` separado. Cualquier rama adicional, incluidas las de prefijo `codex/`, requiere una instrucción explícita del usuario.
