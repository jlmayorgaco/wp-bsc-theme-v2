# BSC-016 — Shipping dinámico: Bogotá vs resto del país sin recarga manual

## Objetivo
Actualizar automáticamente la tarifa de envío en el checkout cuando el usuario cambia ciudad/departamento, mostrando correctamente el precio para Bogotá vs. el resto del país, sin requerir recarga manual de la página.

## Contexto
El checkout actualmente no recalcula el shipping automáticamente al cambiar la ciudad o departamento. El cliente exige esta diferenciación de precios como requisito de operación. WooCommerce tiene el mecanismo de recalculo de shipping vía `update_checkout`, solo hay que dispararlo correctamente.

## Archivos a revisar
- `inc/ajax/checkout-actions.php` — handlers AJAX del checkout
- `js/checkout.js` — eventos del checkout
- `inc/woocommerce.php` — configuración de WooCommerce, posibles filtros de shipping
- `woocommerce/checkout/form-checkout.php` — template del form de checkout

## Implementación exacta
1. En `js/checkout.js`: agregar listener en el campo de ciudad (`#billing_city`) y departamento/estado (`#billing_state`):
   ```javascript
   $(document.body).on('change', '#billing_city, #billing_state', function() {
       $(document.body).trigger('update_checkout');
   });
   ```
2. Verificar en WooCommerce Admin → Ajustes → Envío que existen zonas de envío configuradas correctamente: una para Bogotá/Cundinamarca y otra para el resto del país.
3. En `inc/woocommerce.php`: si se usa lógica custom de pricing de envío, asegurarse de que el hook `woocommerce_package_rates` lee correctamente la ciudad del carrito:
   ```php
   add_filter('woocommerce_package_rates', 'bsc_adjust_shipping_by_city', 10, 2);
   function bsc_adjust_shipping_by_city($rates, $package) {
       $city = $package['destination']['city'] ?? '';
       // lógica de ajuste de precio
       return $rates;
   }
   ```
4. Verificar que `$(document.body).trigger('update_checkout')` dispara el recalculo correcto.
5. Probar que el UI de shipping en el checkout se actualiza visualmente sin necesidad de recargar.

## Qué NO se acepta como solución
- Mostrar los precios de envío estáticos sin actualizar al cambiar ciudad.
- Requerir que el usuario haga click manual en "Recalcular".
- Modificar la lógica de zonas de envío de WooCommerce Admin (eso es configuración, no código).

## Requerimientos
- El campo de ciudad en el checkout es `#billing_city` o `#shipping_city` (verificar el ID real).
- WooCommerce debe tener zonas de envío correctamente configuradas para que este código funcione.

## Criterios de aceptación
- Al cambiar ciudad a "Bogotá" en checkout → la tarifa de envío de Bogotá aparece automáticamente.
- Al cambiar a otra ciudad → la tarifa del resto del país aparece automáticamente.
- No se requiere recarga ni click adicional.

## QA manual
- Ir al checkout con productos → poner ciudad "Bogotá" → verificar precio de envío.
- Cambiar ciudad a "Medellín" → verificar que el precio cambia automáticamente.
- Cambiar de vuelta a "Bogotá" → verificar el precio correcto de Bogotá.
