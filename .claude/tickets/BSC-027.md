# BSC-027 — Diseñar y completar página FAQ

## Objetivo
Completar la página de Preguntas Frecuentes con acordeones claros, diseño BSC, responsive y accesible.

## Contexto
El cliente solicitó esta página en el PDF. `page-faq.php` puede estar vacía o incompleta. Es una página de FAQ con acordeones para preguntas y respuestas sobre productos, envíos, devoluciones y Bubble Points.

## Archivos a revisar
- `page-faq.php` — template de la página

## Implementación exacta
1. En `page-faq.php`: construir el layout con:
   - Sección de título "Preguntas Frecuentes".
   - Grupos de preguntas por categoría (Productos, Envíos, Devoluciones, Bubble Points, Pagos).
   - Cada pregunta como acordeón (`<details>/<summary>` nativo de HTML5 o con CSS/JS).
2. Usar `<details>` y `<summary>` para los acordeones (accesible, sin JS extra):
   ```html
   <details class="bsc-faq-item">
       <summary class="bsc-faq-question">¿Pregunta aquí?</summary>
       <div class="bsc-faq-answer">Respuesta aquí.</div>
   </details>
   ```
3. CSS para los acordeones acorde a la marca BSC: borde, color de fondo, ícono de expand/collapse.
4. El contenido específico de las preguntas debe ser provisto por el cliente. Usar placeholders marcados si no está disponible.
5. Responsive: funciona igual en mobile y desktop.

## Qué NO se acepta como solución
- Inventar respuestas de FAQ sin confirmación del cliente.
- FAQ sin acordeón (todo visible al mismo tiempo).
- Diseño que no sigue la marca BSC.

## Requerimientos
- Acordeones accesibles (navegables por teclado).
- Si el contenido no está confirmado, usar placeholders claros.

## Criterios de aceptación
- La página tiene acordeones funcionando.
- Diseño acorde a la marca BSC.
- Responsive en mobile y desktop.
- Navegable por teclado.

## QA manual
- Ir a `/faq` → verificar acordeones funcionan.
- Verificar en mobile.
- Navegar con Tab y Enter para abrir acordeones → funcional.
