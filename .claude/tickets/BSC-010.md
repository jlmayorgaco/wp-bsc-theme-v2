# BSC-010 — Menú mobile Skin Care idéntico al menú desktop

## Objetivo
Unificar el árbol de navegación del menú móvil con el del menú desktop para Skin Care. Eliminar duplicados (ej. "mascarillas" repetido, categorías duplicadas) y asegurar que ambas versiones usan la misma fuente de datos.

## Contexto
El PDF del cliente pide que el menú mobile de Skin Care quede exactamente igual al de computador y que se quiten duplicados como "mascarilla/piel seca-mixta" duplicados. El menú está hardcodeado como arrays PHP en `header.php`, lo que generó divergencias entre la versión mobile y desktop.

## Archivos a revisar
- `components/header.php` — arrays del menú desktop y mobile
- `components/header/BSC_HeaderNav.class.php` — clase de navegación del header
- `components/header/BSC_MenuNav.class.php` — clase del menú de navegación

## Implementación exacta
1. En `header.php`: identificar los dos arrays separados de menú (desktop y mobile).
2. Crear UNA sola fuente de verdad: un array o función que genere el árbol de categorías. Ejemplo: `bsc_get_skin_care_menu_items()` que retorne el mismo array para ambos usos.
3. Reemplazar los arrays duplicados por una única llamada a esa función.
4. En el array resultante: revisar y eliminar ítems duplicados (verificar que "mascarillas" y otras categorías no aparezcan dos veces).
5. Verificar que el orden de ítems coincide con lo que muestra el menú desktop actual (no reordenar sin aprobación).

## Qué NO se acepta como solución
- Mantener dos arrays divergentes, aunque estén en funciones distintas.
- Cambiar el diseño visual del menú en este ticket (solo datos).
- Modificar `BSC_MenuNav.class.php` sin entender su impacto.

## Requerimientos
- Mobile y desktop deben mostrar exactamente el mismo árbol de Skin Care.
- No hay ítems duplicados.
- El orden debe ser el mismo en ambas versiones.

## Criterios de aceptación
- El menú mobile de Skin Care tiene los mismos ítems que el desktop.
- No aparece ninguna categoría duplicada en el menú mobile.
- Navegar por el menú mobile lleva a las mismas URLs que el desktop.

## QA manual
- Abrir menú desktop en Skin Care → anotar todas las categorías visibles.
- Abrir menú mobile → expandir Skin Care → comparar con la lista anterior.
- Verificar que no hay "mascarillas" repetido ni ninguna categoría duplicada.
- Hacer click en cada categoría mobile → verificar URL correcta.
