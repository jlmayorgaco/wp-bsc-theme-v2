# BSC-011 — Cambiar ícono de cerrar menú mobile: X → hamburguesa

## Objetivo
Cambiar el ícono de cierre del menú mobile de X (×) a hamburguesa (≡) según pedido explícito del cliente en el PDF.

## Contexto
El cliente pidió que el ícono para cerrar el menú mobile sea una hamburguesa, no una X. Actualmente el botón de cierre usa un ícono de X (típico de sidebar).

## Archivos a revisar
- `components/header.php` — botón de cierre del menú mobile (buscar `aria-label="close"` o similar)
- `js/mobile-menu.js` — si cambia el ícono dinámicamente
- `style.css` — si el ícono está definido por CSS

## Implementación exacta
1. En `header.php`: localizar el botón de cierre del menú mobile.
2. Reemplazar el ícono de X por el ícono de hamburguesa. Opciones:
   - Si usa Font Awesome: cambiar `fa-times` por `fa-bars`.
   - Si usa SVG inline: reemplazar el SVG de X por el de tres líneas horizontales.
   - Si usa CSS `::before`/`::after`: actualizar el CSS correspondiente.
3. Mantener `aria-label` descriptivo: `aria-label="Menú"` cuando el menú está cerrado, y un estado visual claro cuando está abierto.
4. Verificar que `mobile-menu.js` no sobreescribe el ícono al cambiar estado.

## Qué NO se acepta como solución
- Cambiar el diseño o comportamiento del menú más allá del ícono.
- Remover el `aria-label` del botón.

## Requerimientos
- El ícono debe verse claramente como hamburguesa (3 líneas horizontales).
- Debe tener `aria-label` accesible.
- No debe cambiar el comportamiento de apertura/cierre.

## Criterios de aceptación
- El botón del menú mobile muestra ícono de hamburguesa (no X) en todo momento.
- El menú sigue abriéndose y cerrándose al hacer tap.
- El botón tiene `aria-label` correcto.

## QA manual
- Abrir menú mobile → verificar ícono hamburguesa.
- Cerrar menú → verificar ícono hamburguesa (no X).
- Verificar accesibilidad con lector de pantalla (aria-label legible).
