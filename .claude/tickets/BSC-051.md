# BSC-051 — Accesibilidad mínima WCAG en navegación, forms y checkout

## Objetivo
Corregir los problemas básicos de accesibilidad: labels en formularios, focus states visibles, navegación por teclado en el menú y checkout, y contraste mínimo de colores.

## Contexto
El issue lista problemas de accesibilidad que también afectan el SEO y la usabilidad general. Usuarios con lectores de pantalla, discapacidades visuales o que navegan solo con teclado deben poder completar una compra. WCAG 2.1 AA es el mínimo estándar.

## Archivos a revisar
- `components/header.php` — menú de navegación (accesibilidad del menú mobile)
- `woocommerce/checkout/form-checkout.php` — formulario de checkout
- `woocommerce/myaccount/` — formularios de Mi Cuenta
- `style.css` — focus states y contraste de colores

## Implementación exacta
1. **Labels en formularios**: verificar que todos los `<input>` tienen `<label>` asociado con `for` + `id`, o `aria-label`.
2. **Focus states visibles**: en CSS, asegurarse de que el outline de focus no está eliminado:
   ```css
   /* NO hacer esto: */
   * { outline: none; }
   
   /* En cambio, usar un outline personalizado: */
   :focus-visible {
       outline: 2px solid #FF69B4; /* color BSC */
       outline-offset: 2px;
   }
   ```
3. **Menú mobile**: el botón de hamburguesa debe tener `aria-expanded="false"/"true"` que cambia con JS al abrir/cerrar el menú.
4. **Botones vs links**: elementos que ejecutan acciones deben ser `<button>`, no `<a>` sin href. Elementos que navegan deben ser `<a>`. (Aplica al add-to-cart, ya corregido en BSC-005).
5. **Contraste**: verificar que el texto sobre fondo de color BSC (rosa, azul) tiene ratio de contraste mínimo 4.5:1 (usar WebAIM Contrast Checker).
6. **Alt text**: verificar que todas las imágenes significativas tienen `alt` descriptivo. Imágenes decorativas tienen `alt=""`.
7. **Skip link**: agregar un link de "Saltar al contenido principal" al inicio del `<body>`:
   ```html
   <a href="#main-content" class="skip-link">Saltar al contenido principal</a>
   ```

## Qué NO se acepta como solución
- Eliminar focus states completamente.
- Aria-labels genéricos como `aria-label="button"`.
- Cambiar el diseño visual de forma significativa solo para accesibilidad.

## Requerimientos
- Focus states deben ser visibles en todos los elementos interactivos.
- El menú mobile debe ser navegable por teclado.
- Las imágenes de productos deben tener alt text descriptivo.

## Criterios de aceptación
- El menú mobile es navegable completamente por teclado (Tab + Enter).
- Los formularios de checkout tienen labels asociados a todos los inputs.
- El skip link funciona y lleva al contenido principal.
- El contraste de los colores principales pasa WCAG AA (4.5:1).
- Los focus states son visibles.

## QA manual
- Navegar la home solo con Tab y Enter → debe ser posible llegar al checkout.
- Abrir el menú mobile con teclado → Tab hasta el botón → Enter para abrir → Tab para navegar → Escape para cerrar.
- Usar VoiceOver (iOS) o TalkBack (Android) en el checkout → los labels se leen correctamente.
- Verificar contraste con WebAIM Contrast Checker para colores BSC.
