# BSC-023 — Bubble Points: revisión visual completa y responsividad

## Objetivo
Dejar la sección de Bubble Points visualmente correcta: cupones/tickets inactivos en grayscale, carrusel/listado legible en mobile, y layout general corregido.

## Contexto
El cliente pide revisión de estilos del sistema de Bubble Points: que los cupones/tickets no activos se vean claramente deshabilitados (grayscale), y que el componente sea responsive. El plugin de Bubble Points vive dentro del theme en `plugins/bubble-points/`.

## Archivos a revisar
- `plugins/bubble-points/views/` — todas las vistas del plugin
- `plugins/bubble-points/hooks/hooks-front.php` — hooks del frontend
- `style.css` — estilos del plugin integrados en el theme
- `page-bubble-points.php` — template de la página de Bubble Points

## Implementación exacta
1. Revisar las vistas en `plugins/bubble-points/views/` para identificar la estructura HTML de los cupones/tickets.
2. En CSS: aplicar grayscale a elementos inactivos/no canjeables:
   ```css
   .bubble-coupon--inactive,
   .bubble-ticket--inactive {
       filter: grayscale(100%);
       opacity: 0.6;
       pointer-events: none;
   }
   ```
3. Verificar que los items inactivos tienen la clase CSS correcta (revisar el PHP del plugin para ver qué clase se agrega).
4. Si el carrusel de puntos usa Swiper u otro slider: verificar configuración responsive con `breakpoints`.
5. Si el listado no es carrusel: aplicar grid responsive:
   ```css
   .bubble-points-list {
       display: grid;
       grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
       gap: 16px;
   }
   ```
6. Verificar que el layout general de la página de Bubble Points no tiene overflow en mobile.

## Qué NO se acepta como solución
- Modificar la lógica de canje de puntos.
- Cambiar el sistema de puntos o cómo se calculan.
- Tocar archivos PHP del plugin más allá de los views/hooks necesarios.

## Requerimientos
- Los items inactivos deben verse claramente diferentes de los activos.
- El componente debe ser usable en pantallas de 375px de ancho.

## Criterios de aceptación
- Cupones/tickets inactivos se ven en grayscale.
- El carrusel o listado de puntos es responsive en mobile.
- El layout no tiene overflow en pantallas pequeñas.
- Los items activos se ven normales (sin grayscale).

## QA manual
- Ir a `/bubble-points` en mobile → verificar layout responsive.
- Verificar que items inactivos están en grayscale.
- Verificar que items activos no tienen grayscale.
- Verificar en desktop que no hay cambios no deseados.
