# BSC-001 — Reparar componente WhatsApp y mensaje configurable

## Objetivo
Reconstruir el botón flotante de WhatsApp que está completamente roto (`components/whatsapp.php` contiene código scratch en vez de implementación real). Centralizar número y mensaje en un helper único para evitar duplicados en todo el proyecto.

## Contexto
El archivo `components/whatsapp.php` contiene cálculos de shipping aleatorios en vez del botón flotante. El footer referencia este componente pero no muestra nada. WhatsApp es el canal de soporte clave del negocio. El número oficial es `+573156922859`. El cliente también pidió que el mensaje sea configurable por contexto (home, producto, soporte).

## Archivos a revisar
- `components/whatsapp.php` — reescribir completo
- `components/footer.php` — verificar llamada al componente
- `components/header.php` — verificar si hay número hardcodeado
- `functions.php` o nuevo `inc/bsc-contact-options.php` — helper central

## Implementación exacta
1. Crear función helper en `inc/bsc-contact-options.php`:
   ```php
   function bsc_get_whatsapp_url( $context = 'general' ) {
       $phone   = '573156922859';
       $messages = [
           'general' => 'Hola, quiero más información sobre Bubble Skin Care.',
           'product' => 'Hola, tengo una pregunta sobre un producto.',
           'support' => 'Hola, necesito ayuda con mi pedido.',
       ];
       $msg = $messages[ $context ] ?? $messages['general'];
       return 'https://api.whatsapp.com/send?phone=' . $phone . '&text=' . rawurlencode( $msg );
   }
   ```
2. Reescribir `components/whatsapp.php` con un `<a>` flotante que use `bsc_get_whatsapp_url('general')`, ícono de WhatsApp (FA o SVG inline), y clase CSS `whatsapp-float`.
3. Verificar que `footer.php` llama correctamente `get_template_part('components/whatsapp')`.
4. Reemplazar cualquier link de WhatsApp hardcodeado en `header.php` con `bsc_get_whatsapp_url('product')`.
5. Incluir `inc/bsc-contact-options.php` desde `functions.php` con `require_once`.

## Qué NO se acepta como solución
- Hardcodear número en más de un lugar.
- Dejar el archivo `whatsapp.php` con el contenido actual (cálculos de envío).
- Usar plugin externo para este componente.

## Requerimientos
- El botón debe ser visible en mobile y desktop.
- No debe romper el layout del footer.
- Debe usar el número `+573156922859`.

## Criterios de aceptación
- El botón flotante de WhatsApp aparece en todas las páginas del sitio.
- Al hacer click abre WhatsApp con el número correcto y un mensaje pre-llenado.
- No hay números de WhatsApp hardcodeados fuera del helper.
- Funciona en desktop y mobile.

## QA manual
- Ir a Home → hacer click en botón WhatsApp → verificar número y mensaje.
- Ir a una página de producto → hacer click → verificar mensaje de contexto.
- Verificar en mobile (simulador o dispositivo real).
- Buscar `573156922859` en el código fuera del helper → no debe aparecer.
