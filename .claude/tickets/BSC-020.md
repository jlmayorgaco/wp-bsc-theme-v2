# BSC-020 — Mi Cuenta: tabs al 100% width y scroll al inicio al cambiar tab

## Objetivo
En la página de Mi Cuenta, los tabs de navegación deben ocupar el 100% del ancho disponible en mobile, y al cambiar de tab la pantalla debe hacer scroll automático al inicio del contenido del tab seleccionado.

## Contexto
El PDF pide estas dos mejoras para la navegación de Mi Cuenta. Los tabs en mobile quedan cortados o con ancho incorrecto, y al cambiar de tab el usuario debe hacer scroll manual para ver el contenido, lo que es una mala UX especialmente en pedidos.

## Archivos a revisar
- `woocommerce/myaccount/` — templates de my account
- `page-mi-cuenta.php` — template de Mi Cuenta custom
- `style.css` — estilos de las tabs de my account
- `js/tabs.js` — lógica de tabs existente (si aplica)

## Implementación exacta
1. En CSS, para las tabs de Mi Cuenta en mobile:
   ```css
   @media (max-width: 767px) {
       .woocommerce-MyAccount-navigation ul {
           display: flex;
           flex-wrap: wrap;
       }
       .woocommerce-MyAccount-navigation ul li {
           flex: 1 1 50%; /* o 100% si son tabs apiladas */
           text-align: center;
       }
   }
   ```
2. En JS (en `page-mi-cuenta.php` o `js/tabs.js`), al cambiar de tab:
   ```javascript
   $('.woocommerce-MyAccount-navigation a').on('click', function() {
       setTimeout(function() {
           const $content = $('.woocommerce-MyAccount-content');
           if ($content.length) {
               $('html, body').animate({
                   scrollTop: $content.offset().top - 80 // offset del header
               }, 300);
           }
       }, 100); // esperar a que el tab cambie
   });
   ```
3. El offset de `80px` debe corresponder a la altura real del header fijo.

## Qué NO se acepta como solución
- Scroll al top de la página completa (debe ser al inicio del contenido del tab).
- Cambiar el diseño visual de las tabs más allá del ancho.

## Requerimientos
- El scroll solo debe aplicarse al cambiar de tab (no en la carga inicial de la página).
- El offset debe compensar el header fijo para que el contenido no quede tapado.

## Criterios de aceptación
- En mobile: los tabs de Mi Cuenta ocupan el ancho completo disponible.
- Al cambiar de tab: la pantalla hace scroll automático al inicio del contenido.
- El contenido no queda tapado por el header fijo.

## QA manual
- Ir a Mi Cuenta en mobile → verificar que los tabs tienen ancho completo.
- Hacer click en tab "Pedidos" → verificar scroll automático al inicio del contenido.
- Hacer click en tab "Mi dirección" → mismo comportamiento.
- Verificar en desktop que no hay cambios no deseados.
