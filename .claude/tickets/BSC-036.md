# BSC-036 — Doble inventario: stock web (bodega) y stock showroom (tienda)

## Objetivo
Implementar un sistema de stock dual: `_stock_tienda` (showroom/vitrina) y `_stock_bodega` (bodega/despacho). Las ventas web descuentan bodega; las ventas presenciales descuentan tienda. Sin sobreventa.

## Contexto
El PDF pide manejar inventario web y ventas físicas por separado. NEW_FEATURES.md tiene el modelo detallado. El WooCommerce nativo solo maneja un stock; el dual requiere meta fields custom y lógica de deducción correcta.

## Archivos a revisar
- Nuevo `includes/class-bsc-stock.php` — clase de gestión de stock dual
- `inc/admin/product-covers.php` — campos admin de productos (agregar los nuevos campos de stock)
- `inc/woocommerce.php` — hooks para descontar stock al completar pedido

## Implementación exacta
1. En `inc/admin/product-covers.php`, agregar campos al panel de inventario del producto:
   ```php
   woocommerce_wp_number_input(['id' => '_stock_tienda', 'label' => 'Stock en Tienda', 'desc_tip' => true, 'description' => 'Unidades disponibles en showroom']);
   woocommerce_wp_number_input(['id' => '_stock_bodega', 'label' => 'Stock en Bodega', 'desc_tip' => true, 'description' => 'Unidades disponibles para despacho web']);
   woocommerce_wp_select(['id' => '_envio_tipo', 'label' => 'Tipo de envío', 'options' => ['bodega' => 'Desde Bodega', 'tienda' => 'Desde Tienda', 'ambos' => 'Ambos']]);
   ```
2. Guardar los meta en `woocommerce_process_product_meta`:
   ```php
   foreach (['_stock_tienda', '_stock_bodega', '_envio_tipo'] as $key) {
       update_post_meta($post_id, $key, sanitize_text_field($_POST[$key] ?? ''));
   }
   ```
3. Crear `includes/class-bsc-stock.php`:
   ```php
   class BSC_Stock {
       public static function deduct_bodega($order_id) {
           $order = wc_get_order($order_id);
           foreach ($order->get_items() as $item) {
               $product_id = $item->get_product_id();
               $qty = $item->get_quantity();
               $current = (int) get_post_meta($product_id, '_stock_bodega', true);
               update_post_meta($product_id, '_stock_bodega', max(0, $current - $qty));
           }
       }
       public static function deduct_tienda($order_id) {
           $order = wc_get_order($order_id);
           foreach ($order->get_items() as $item) {
               $product_id = $item->get_product_id();
               $qty = $item->get_quantity();
               $current = (int) get_post_meta($product_id, '_stock_tienda', true);
               update_post_meta($product_id, '_stock_tienda', max(0, $current - $qty));
           }
       }
   }
   ```
4. En `inc/woocommerce.php`: hook al completar pedido web para descontar bodega:
   ```php
   add_action('woocommerce_order_status_processing', ['BSC_Stock', 'deduct_bodega']);
   ```
5. Las ventas showroom descontarán tienda desde el flujo del BSC-037.

## Qué NO se acepta como solución
- Descontar ambos stocks en una venta web.
- Mostrar stock total como `_stock_tienda + _stock_bodega` sin lógica de negocio definida.
- Sin validación de stock mínimo (resultado no puede ser negativo).

## Requerimientos
- Los campos `_stock_tienda` y `_stock_bodega` son independientes.
- El resultado del descuento nunca puede ser negativo (`max(0, ...)`).
- Los campos son visibles y editables en el panel de producto de WP Admin.

## Criterios de aceptación
- En WP Admin, cada producto tiene los campos "Stock en Tienda" y "Stock en Bodega".
- Al completar un pedido web, `_stock_bodega` se descuenta correctamente.
- El stock nunca queda en negativo.
- Los campos se guardan y persisten correctamente.

## QA manual
- Ir a WP Admin → Producto → agregar 10 en stock bodega → guardar.
- Crear pedido de 3 unidades → completarlo → verificar que bodega queda en 7.
- Verificar que tienda no cambió.
- Verificar que el resultado nunca es negativo (probar con qty mayor al stock).
