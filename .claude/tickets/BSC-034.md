# BSC-034 — Exportación de pedidos para empaque (CSV + print view)

## Objetivo
Permitir al operador seleccionar múltiples pedidos en el admin BSC y exportarlos como CSV limpio o como vista HTML imprimible para preparar el empaque.

## Contexto
El PDF pide seleccionar pedidos y descargar un PDF o ZIP con lo que toca empacar. El ROADMAP recomienda empezar con v1: CSV limpio + print view HTML/PDF básico. La v2 (ZIP con fichas individuales) es futura.

## Archivos a revisar
- `admin/bsc-orders-page.php` — agregar checkboxes de selección y botón de exportar
- Nuevo `admin/bsc-export.php` — handler de exportación
- `admin/class-bsc-orders-table.php` — columna de checkbox

## Implementación exacta
1. En `admin/class-bsc-orders-table.php`: agregar columna `cb` con checkbox para cada pedido.
2. En `admin/bsc-orders-page.php`: agregar formulario con botones de acción bulk:
   - Botón "Exportar CSV" → submits el form con `action=export_csv`.
   - Botón "Vista de empaque" → submits el form con `action=print_packing`.
3. Crear `admin/bsc-export.php` con dos funciones:
   - `bsc_export_orders_csv($order_ids)`: genera CSV con columnas: ID, Fecha, Cliente, Email, Teléfono, Dirección, Ítems (nombre + qty + SKU), Total, Estado.

   - `bsc_render_packing_view($order_ids)`: renderiza HTML imprimible con los pedidos seleccionados, formateado para imprimir (CSS de print media).
4. El handler debe verificar nonce y capability `edit_orders` antes de procesar.

## Qué NO se acepta como solución
- Exportar TODOS los pedidos sin selección previa.
- Export sin nonce.
- CSV con encoding que rompa tildes/ñ (usar UTF-8 BOM).

## Requerimientos
- El CSV debe usar UTF-8 con BOM para compatibilidad con Excel.
- La vista de empaque debe ser imprimible (usar CSS `@media print`).
- El export solo incluye los pedidos seleccionados.

## Criterios de aceptación
- Seleccionar 3 pedidos → click "Exportar CSV" → se descarga CSV con esos 3 pedidos.
- El CSV abre correctamente en Excel con tildes y ñ.
- Seleccionar pedidos → "Vista de empaque" → página imprimible con detalle de cada pedido.

## QA manual
- Seleccionar 2-3 pedidos → exportar CSV → abrir en Excel → verificar datos correctos.
- Seleccionar pedidos → vista de empaque → Ctrl+P → se ve imprimible.
- Intentar acceder al endpoint sin nonce → debe fallar con error.
