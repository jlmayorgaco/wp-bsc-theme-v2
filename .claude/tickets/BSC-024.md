# BSC-024 — Edit address / mis datos / envío y dirección: responsividad

## Objetivo
Corregir los formularios de Mi Cuenta (editar dirección, mis datos, dirección de envío) para que sean completamente usables en mobile: sin overflow, inputs clicables, spacing consistente.

## Contexto
El PDF pide responsivizar estas vistas de Mi Cuenta. Los formularios de WooCommerce pueden tener columns flotadas o grids que se rompen en pantallas pequeñas, dejando inputs cortados o con z-index incorrecto en mobile.

## Archivos a revisar
- `woocommerce/myaccount/edit-address.php` — template de editar dirección
- `woocommerce/myaccount/edit-account.php` — template de editar cuenta
- `style.css` — estilos de los forms de my account

## Implementación exacta
1. En CSS, para los formularios de Mi Cuenta en mobile:
   ```css
   @media (max-width: 767px) {
       .woocommerce-address-fields__field-wrapper .form-row,
       .woocommerce-EditAccountForm .form-row {
           float: none;
           clear: both;
           width: 100%;
           padding: 0;
           margin-bottom: 16px;
       }
       .woocommerce-address-fields__field-wrapper .form-row input,
       .woocommerce-EditAccountForm .form-row input {
           width: 100%;
           box-sizing: border-box;
           font-size: 16px; /* previene zoom en iOS */
           padding: 12px;
       }
   }
   ```
2. Verificar que los selects (`<select>`) también tienen `width: 100%` en mobile.
3. Verificar que el botón de guardar tiene `width: 100%` en mobile.
4. El `font-size: 16px` en inputs es crítico para iOS: evita que el teclado haga zoom.

## Qué NO se acepta como solución
- Cambiar la lógica de los formularios (solo CSS responsivo).
- Modificar los templates PHP más de lo necesario.

## Requerimientos
- Font-size mínimo de 16px en inputs de mobile (para prevenir zoom de iOS).
- Inputs con `box-sizing: border-box` para no salirse del contenedor.

## Criterios de aceptación
- Formulario de editar dirección se ve y funciona en mobile sin overflow.
- Formulario de mis datos se ve y funciona en mobile sin overflow.
- Los inputs son clicables y no se ven cortados.
- El teclado no hace zoom al enfocar un input en iOS.

## QA manual
- Ir a Mi Cuenta → Editar dirección en iOS Safari → enfocar un input → verificar que el teclado no hace zoom.
- Verificar que todos los inputs y el botón de guardar son accesibles (no quedan fuera de pantalla).
- Verificar en Android Chrome.
- Verificar en desktop que no hay cambios no deseados.
