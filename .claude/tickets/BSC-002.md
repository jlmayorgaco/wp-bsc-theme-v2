# BSC-002 — Eliminar URLs localhost y hardcodes de producción

## Objetivo
Reemplazar todas las URLs absolutas con dominio `bsc.local` o `http://localhost` por funciones dinámicas de WordPress. Sin este fix el sitio no puede deployarse a producción.

## Contexto
El issue report (CRIT-002) detectó múltiples URLs `http://bsc.local/` en `components/header.php` (líneas ~266, ~312, ~319) que apuntan a imágenes de menú y links de navegación. En producción estos links generan 404 y las imágenes no cargan.

## Archivos a revisar
- `components/header.php` — links e imágenes del mega-menú
- `components/footer.php` — cualquier link absoluto
- `functions.php` — cualquier constante o string hardcodeado
- Todos los archivos en `components/` — búsqueda global de `bsc.local`
- `js/` — scripts con URLs hardcodeadas

## Implementación exacta
1. Ejecutar búsqueda global de `bsc.local` en todos los archivos PHP y JS del theme.
2. Para imágenes del theme usar `get_template_directory_uri() . '/images/...'`.
3. Para imágenes de uploads usar `wp_get_attachment_url( $id )` o la URL ya guardada en la base de datos (no hardcodear).
4. Para links de navegación usar `home_url('/ruta/')` o `get_permalink( $page_id )`.
5. Para el blog usar `get_permalink( get_option('page_for_posts') )`.
6. Para links de categorías usar `get_term_link( $term )`.
7. Reemplazar cada instancia encontrada con la función dinámica correcta.
8. Verificar que no queden strings `localhost` o `.local` en ningún archivo del theme.

## Qué NO se acepta como solución
- Dejar una sola URL con `bsc.local`.
- Usar strings manuales para URLs internas.
- Hacer find/replace global sin revisar el contexto de cada ocurrencia.

## Requerimientos
- No cambiar la lógica de navegación, solo las URLs.
- Cada reemplazo debe usar la función WP más apropiada para el contexto.

## Criterios de aceptación
- Búsqueda global de `bsc.local` en el theme devuelve 0 resultados.
- Búsqueda global de `http://localhost` en el theme devuelve 0 resultados.
- Toda la navegación del menú funciona sin links rotos.
- Las imágenes del mega-menú cargan correctamente.

## QA manual
- Navegar menú completo: Skin Care, Blog, Rutina, Contacto → todos los links deben funcionar.
- Verificar que las imágenes de cover del menú cargan.
- Probar en mobile.
- Hacer búsqueda en código: `grep -r "bsc.local" .` → resultado vacío.
