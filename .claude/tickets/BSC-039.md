# BSC-039 — Cachear queries repetidas con transients

## Objetivo
Identificar y cachear las queries más repetidas del sitio (home sliders, categorías del menú, productos de la home) usando `set_transient()` / `get_transient()` para reducir la carga en la base de datos.

## Contexto
El issue (PERF-002) identifica queries sin caché. Las queries de la home (sliders de productos, tabs por tipo de piel, marcas) se ejecutan en cada page load. Con tráfico moderado esto sobrecarga la DB.

## Archivos a revisar
- `front-page.php` — queries de la home (sliders, tabs)
- `components/products/slider.php` — query del slider de productos
- `components/header.php` — si hay queries del menú
- `inc/setup/theme-setup.php` — para invalidar transients al actualizar productos

## Implementación exacta
1. En `components/products/slider.php` (o donde se ejecute la query del slider), envolver la query con transient:
   ```php
   function bsc_get_slider_products($args_key, $query_args) {
       $cache_key = 'bsc_slider_' . md5($args_key);
       $products = get_transient($cache_key);
       if ($products === false) {
           $q = new WP_Query($query_args);
           $products = $q->posts;
           set_transient($cache_key, $products, HOUR_IN_SECONDS);
       }
       return $products;
   }
   ```
2. Invalidar transients cuando se actualiza/publica un producto:
   ```php
   add_action('save_post_product', 'bsc_clear_slider_cache');
   function bsc_clear_slider_cache() {
       // Eliminar todas las claves bsc_slider_*
       global $wpdb;
       $wpdb->query("DELETE FROM {$wpdb->options} WHERE option_name LIKE '_transient_bsc_slider_%'");
   }
   ```
3. Para el menú de categorías en `header.php` (si hace queries de taxonomía):
   ```php
   $categories = get_transient('bsc_menu_categories');
   if (!$categories) {
       $categories = get_terms(['taxonomy' => 'product_cat', 'parent' => 0, 'hide_empty' => true]);
       set_transient('bsc_menu_categories', $categories, 12 * HOUR_IN_SECONDS);
   }
   ```
4. Limpiar `bsc_menu_categories` cuando se actualiza una categoría: hook en `edited_term` y `created_term`.

## Qué NO se acepta como solución
- Transients que nunca se invalidan al actualizar contenido.
- Transients con TTL mayor a 24 horas para contenido que cambia frecuentemente.
- Cachear respuestas AJAX de carrito (WooCommerce ya maneja esto por fragments).

## Requerimientos
- Los transients se invalidan cuando el contenido relevante cambia.
- TTL máximo de 1 hora para queries de productos; 12 horas para categorías.

## Criterios de aceptación
- La query del slider no se ejecuta en cada page load (se usa caché).
- Al publicar/actualizar un producto, el caché del slider se invalida.
- Las categorías del menú usan caché y se invalidan al cambiar categorías.

## QA manual
- Activar Query Monitor plugin en staging → verificar número de queries en la home.
- Publicar un producto → verificar que la home muestra el producto nuevo (caché invalidado).
- Comparar número de queries con y sin caché en la home.
