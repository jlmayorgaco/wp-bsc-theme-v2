# BSC-030 — Menú admin BSC custom

## Objetivo
Crear un menú de administración personalizado "BSC" con submenús para Pedidos, Productos, Informes y Configuración, visible según el rol del usuario. Los roles operativos no deben ver el backend completo de WordPress/WooCommerce.

## Contexto
NEW_FEATURES.md propone una estructura de menú BSC con submenús por rol. El menú debe coexistir con el admin de WP pero ser la entrada principal para roles `bsc_operator` y `bsc_employee`. El admin completo (Administrator) ve ambos menús.

## Archivos a revisar
- Nuevo `admin/bsc-admin-menu.php` — setup del menú
- Nuevo `admin/bsc-dashboard.php` — vista del dashboard principal BSC
- `functions.php` — para requerir el nuevo archivo

## Implementación exacta
1. Crear `admin/bsc-admin-menu.php`:
   ```php
   function bsc_add_admin_menu() {
       add_menu_page(
           'BSC Dashboard',
           'BSC',
           'read',
           'bsc-dashboard',
           'bsc_render_dashboard',
           'dashicons-store',
           3
       );
       add_submenu_page('bsc-dashboard', 'Pedidos BSC', 'Pedidos', 'edit_orders', 'bsc-orders', 'bsc_render_orders_page');
       add_submenu_page('bsc-dashboard', 'Productos BSC', 'Productos', 'edit_products', 'bsc-products', 'bsc_render_products_page');
       add_submenu_page('bsc-dashboard', 'Informes BSC', 'Informes', 'manage_woocommerce', 'bsc-reports', 'bsc_render_reports_page');
       add_submenu_page('bsc-dashboard', 'Configuración BSC', 'Configuración', 'manage_options', 'bsc-settings', 'bsc_render_settings_page');
   }
   add_action('admin_menu', 'bsc_add_admin_menu');
   ```
2. Crear `admin/bsc-dashboard.php` con la función `bsc_render_dashboard()`: mostrar widgets básicos (órdenes de hoy, estado de pedidos). Para este ticket, puede ser un placeholder simple con los datos básicos.
3. Crear stubs vacíos para `bsc_render_orders_page`, `bsc_render_products_page`, `bsc_render_reports_page`, `bsc_render_settings_page` (se implementan en tickets BSC-031, BSC-034, BSC-035).
4. Requerir `admin/bsc-admin-menu.php` desde `functions.php`.
5. Para roles `bsc_operator` y `bsc_employee`: ocultar los menús de WP que no les corresponden con `remove_menu_page()` en el hook `admin_menu`.

## Qué NO se acepta como solución
- Menú visible para todos los roles por igual.
- Stub pages sin ningún contenido (al menos un `<h1>` con el nombre de la sección).

## Requerimientos
- El menú "BSC" aparece en la barra lateral del admin.
- La visibilidad de submenús se controla por capability.
- No afectar el acceso del Administrator al menú normal de WP.

## Criterios de aceptación
- El menú "BSC" aparece en el admin de WordPress.
- Submenú "Pedidos" visible para `bsc_operator` y `bsc_employee`.
- Submenú "Productos" visible solo para `bsc_employee` y admin.
- Submenú "Informes" y "Configuración" solo para admin.
- Los roles operativos no ven el menú completo de WooCommerce nativo.

## QA manual
- Como admin: verificar que aparece el menú BSC con todos los submenús.
- Como `bsc_operator`: verificar que solo ve "Pedidos" bajo BSC.
- Como `bsc_employee`: verificar que ve "Pedidos" y "Productos" bajo BSC.
- Hacer click en cada submenú accesible → carga sin error.
