# BSC-021 — Pedidos mobile: tabla → lista con chip rosado para número de orden

## Objetivo
Reemplazar la tabla de pedidos en Mi Cuenta por una lista tipo cards en mobile, donde el número de orden aparece en un chip rosado con letras negras. El desktop puede mantener la tabla o diseño adecuado.

## Contexto
El PDF pide reemplazar la tabla de pedidos por una lista legible en mobile y usa chips rosados para el número de orden (`#1234` en chip rosado). Las tablas con muchas columnas son ilegibles en pantallas pequeñas.

## Archivos a revisar
- `woocommerce/myaccount/orders.php` — template de la lista de pedidos
- `style.css` — estilos de la tabla de pedidos y nuevas cards

## Implementación exacta
1. En `woocommerce/myaccount/orders.php`: envolver cada fila de pedido en un div `.bsc-order-card` en mobile (usando CSS para ocultar/mostrar alternativamente).
2. Alternativa más limpia: modificar el template para que en mobile renderice cards:
   ```php
   foreach ($customer_orders->orders as $customer_order) {
       $order = wc_get_order($customer_order);
       ?>
       <div class="bsc-order-card">
           <div class="bsc-order-card__number">
               <span class="bsc-order-chip">#<?php echo $order->get_order_number(); ?></span>
           </div>
           <div class="bsc-order-card__date"><?php echo $order->get_date_created()->date_i18n(get_option('date_format')); ?></div>
           <div class="bsc-order-card__status"><?php echo wc_get_order_status_name($order->get_status()); ?></div>
           <div class="bsc-order-card__total"><?php echo $order->get_formatted_order_total(); ?></div>
           <div class="bsc-order-card__actions">
               <a href="<?php echo $order->get_view_order_url(); ?>">Ver pedido</a>
           </div>
       </div>
       <?php
   }
   ```
3. CSS para el chip rosado:
   ```css
   .bsc-order-chip {
       background: #FFB6C1; /* rosado BSC */
       color: #000;
       padding: 4px 10px;
       border-radius: 20px;
       font-weight: 600;
       font-size: 14px;
   }
   ```
4. En mobile: mostrar las cards `.bsc-order-card` y ocultar la tabla `<table.woocommerce-orders-table>`.
5. En desktop: mantener la tabla original.

## Qué NO se acepta como solución
- Eliminar la tabla en desktop.
- Chip de color diferente al rosado.
- Cards sin el número de orden visible.

## Requerimientos
- El chip rosado usa el color de la paleta BSC.
- Las cards deben mostrar: número de orden, fecha, estado y total.
- El link a "Ver pedido" debe funcionar.

## Criterios de aceptación
- En mobile: se ven cards con chip rosado para el número de orden.
- El color del chip es rosado con texto negro.
- Cada card tiene fecha, estado, total y link a detalles.
- En desktop: la tabla se mantiene (o diseño adecuado).

## QA manual
- Ir a Mi Cuenta → Pedidos en mobile → verificar cards con chip rosado.
- Click en "Ver pedido" → va a detalle correcto.
- Verificar en desktop → tabla no afectada.
