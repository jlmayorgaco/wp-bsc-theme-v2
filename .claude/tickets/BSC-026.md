# BSC-026 — Diseñar y completar página Shipping & Returns

## Objetivo
Completar la página de Envíos y Devoluciones con el contenido y diseño correcto acorde a la marca BSC. Debe ser responsive y legible.

## Contexto
El cliente solicitó esta página en el PDF. `page-shipping-returns.php` puede estar vacía o incompleta. Es una página estática de información pero debe seguir el diseño BSC.

## Archivos a revisar
- `page-shipping-returns.php` — template de la página

## Implementación exacta
1. En `page-shipping-returns.php`: construir el contenido con secciones:
   - **Tiempos de envío**: tabla o cards con destinos y tiempos estimados (Bogotá, resto del país, etc.).
   - **Costos de envío**: información de tarifas.
   - **Política de devoluciones**: pasos claros para devolver un producto.
   - **Condiciones**: productos que aplican y que no aplican para devolución.
2. Usar clases CSS BSC para headings, tablas y cards.
3. El contenido específico (tarifas, tiempos) debe ser provisto por el cliente. Si no está disponible, usar placeholders `[PENDIENTE: completar con información real]`.
4. Responsive: la tabla de tarifas debe ser scrollable en mobile o convertida a cards.

## Qué NO se acepta como solución
- Inventar tarifas o políticas específicas sin confirmación del cliente.
- Diseño que no siga la marca BSC.

## Requerimientos
- Contenido de policies real debe ser confirmado por el cliente.
- Si el contenido no está confirmado, usar placeholders claramente marcados.

## Criterios de aceptación
- La página tiene estructura y diseño completo acorde a BSC.
- Responsive en mobile y desktop.
- Los placeholders están marcados si el contenido exacto no está disponible.

## QA manual
- Ir a `/shipping-returns` → verificar diseño y contenido.
- Verificar en mobile → responsive correcto.
- Verificar que los links de navegación desde el footer/header a esta página funcionan.
