# BSC-015 — Producto: agregar bloque de 3 imágenes extra debajo del summary

## Objetivo
Agregar un bloque configurable de hasta 3 imágenes extra debajo del summary del producto. En desktop se muestran en fila horizontal, en mobile en columna vertical.

## Contexto
El cliente pide que cada producto pueda tener 3 imágenes adicionales de presentación/detalle debajo del area del título/precio/botón. Estas imágenes deben ser configurables por producto (no globales). Son contenido editorial, no la galería técnica de WooCommerce. Para ello debe crearse en la vista de prducto un selector de imagenes para tal modtivo, en desktop se deben ver en row, y en mobile en column

## Archivos a revisar
- `woocommerce/single-product.php` — template del producto, donde se agregará el bloque
- `inc/admin/product-covers.php` — campos admin custom de productos existentes
- CSS en `style.css` — estilos del bloque nuevo

## Implementación exacta
1. En `inc/admin/product-covers.php` (o crear si no existe), agregar 3 campos de tipo imagen en el panel del producto en WP Admin:
   ```php
   // En woocommerce_product_options_general_product_data o similar
   for ($i = 1; $i <= 3; $i++) {
       woocommerce_wp_text_input([
           'id'          => "_bsc_extra_image_{$i}",
           'label'       => "Imagen extra {$i} (URL)",
           'description' => "URL de imagen extra {$i} para la página del producto",
       ]);
   }
   ```
   O mejor: usar un media uploader field para cada imagen.
2. Guardar los meta en `woocommerce_process_product_meta`:
   ```php
   for ($i = 1; $i <= 3; $i++) {
       $key = "_bsc_extra_image_{$i}";
       update_post_meta( $post_id, $key, esc_url_raw( $_POST[$key] ?? '' ) );
   }
   ```
3. En `woocommerce/single-product.php`, después del cierre del summary o usando el hook `woocommerce_after_single_product_summary`, agregar:
   ```php
   add_action('woocommerce_after_single_product_summary', 'bsc_render_extra_images', 25);
   function bsc_render_extra_images() {
       global $post;
       $images = [];
       for ($i = 1; $i <= 3; $i++) {
           $url = get_post_meta($post->ID, "_bsc_extra_image_{$i}", true);
           if ($url) $images[] = $url;
       }
       if (empty($images)) return;
       echo '<div class="bsc-product-extra-images">';
       foreach ($images as $url) {
           echo '<img src="' . esc_url($url) . '" alt="" loading="lazy">';
       }
       echo '</div>';
   }
   ```
4. En CSS:
   ```css
   .bsc-product-extra-images {
       display: flex;
       gap: 16px;
       margin-top: 32px;
   }
   .bsc-product-extra-images img {
       flex: 1;
       width: 100%;
       object-fit: cover;
   }
   @media (max-width: 767px) {
       .bsc-product-extra-images {
           flex-direction: column;
       }
   }
   ```
5. Productos sin imágenes extra no muestran el bloque (el `if (empty($images)) return` lo garantiza).

## Qué NO se acepta como solución
- Mostrar las imágenes extra dentro de la galería principal de WooCommerce.
- Hardcodear URLs de imágenes.
- Afectar productos que no tienen las imágenes configuradas.

## Requerimientos
- Las imágenes extra son opcionales por producto.
- Desktop: fila horizontal.
- Mobile: columna vertical.
- No afectar el layout de productos sin imágenes extra.

## Criterios de aceptación
- En WP Admin, en la edición de un producto, aparecen 3 campos para imágenes extra.
- Las imágenes guardadas aparecen debajo del summary del producto en el frontend.
- Desktop: fila de 3. Mobile: columna de 3.
- Producto sin imágenes extra no muestra el bloque.

## QA manual
- Ir a WP Admin → Producto → agregar URLs en los 3 campos → Guardar.
- Ver el producto en frontend → verificar las 3 imágenes en fila.
- Verificar en mobile → columna.
- Ir a un producto sin imágenes extra → no debe aparecer el bloque.
