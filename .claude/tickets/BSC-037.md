# BSC-037 — Usuario showroom: flujo de venta presencial simplificado

## Objetivo
Permitir registrar ventas presenciales en el showroom desde el admin BSC, con métodos de pago físicos (efectivo, transferencia, tarjeta presencial), descontando stock de tienda y generando el pedido en WooCommerce.

## Contexto
El PDF pide un flujo de venta física desde el admin para el showroom. Una venta presencial necesita: seleccionar productos, ingresar datos del cliente (o usar cliente anónimo), seleccionar método de pago físico y registrar el pedido. El inventario descontado es `_stock_tienda`.

## Archivos a revisar
- Nuevo `admin/bsc-showroom-page.php` — template de la pantalla de venta presencial
- `includes/class-bsc-stock.php` — método `deduct_tienda` (del BSC-036)
- `admin/bsc-admin-menu.php` — agregar submenú "Venta Presencial" (solo admin/operador)

## Implementación exacta
1. Agregar submenú "Venta Presencial" en `admin/bsc-admin-menu.php` con capability `edit_orders`.
2. Crear `admin/bsc-showroom-page.php` con el formulario de venta presencial:
   - Campo de búsqueda/selección de productos (búsqueda por nombre o SKU).
   - Campo de cantidad por producto.
   - Datos del cliente: nombre, email (opcional), teléfono (opcional).
   - Selector de método de pago: efectivo, transferencia, tarjeta presencial.
   - Botón "Registrar venta".
3. Handler AJAX `bsc_register_showroom_sale`:
   ```php
   // 1. Verificar nonce y capability
   // 2. Crear el pedido WooCommerce programáticamente:
   $order = wc_create_order(['customer_id' => 0]);
   foreach ($items as $item) {
       $order->add_product(wc_get_product($item['id']), $item['qty']);
   }
   $order->set_payment_method($payment_method); // 'efectivo', 'transferencia', etc.
   $order->set_billing_first_name($customer_name);
   $order->set_status('completed');
   $order->calculate_totals();
   $order->save();
   // 3. Descontar stock_tienda
   BSC_Stock::deduct_tienda($order->get_id());
   // 4. Retornar success con el ID del pedido
   ```
4. La página debe mostrar los últimas 10 ventas presenciales registradas para tener historial inmediato.

## Qué NO se acepta como solución
- Flujo que descuenta `_stock_bodega` en vez de `_stock_tienda`.
- Crear pedidos sin estado (deben quedar en `completed` para contabilizarse).
- Handler sin nonce ni capability.

## Requerimientos
- Solo usuarios con `edit_orders` pueden registrar ventas presenciales.
- Los pedidos showroom deben aparecer en el reporte mensual (BSC-035).
- Los pedidos creados tienen un meta `_bsc_is_showroom_sale = 1` para identificarlos.

## Criterios de aceptación
- El operador puede registrar una venta presencial desde el admin BSC.
- La venta descuenta `_stock_tienda` correctamente.
- El pedido aparece en WooCommerce con estado `completed`.
- El pedido tiene el meta `_bsc_is_showroom_sale = 1`.
- El reporte mensual incluye la venta presencial.
