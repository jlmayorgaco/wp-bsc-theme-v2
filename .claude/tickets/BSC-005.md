# BSC-005 — iPad/touch: add-to-cart confiable

## Objetivo
Hacer que el add-to-cart funcione de forma confiable en dispositivos iPad y tablet con pantalla táctil. El problema actual es que el tap no dispara el AJAX handler de forma consistente.

## Contexto
El issue (CRIT-004) confirma que en iPad el evento `click` en el anchor `<a href="?add-to-cart=...">` causa conflictos: el link navega a la URL antes de que el AJAX handler pueda interceptarlo, o el doble tap genera eventos duplicados. Esto bloquea completamente el add-to-cart para usuarios de iPad/tablet.

## Archivos a revisar
- `components/products/card.php` — elemento del botón add-to-cart (línea ~129)
- `js/cart.js` — event listener de add-to-cart

## Implementación exacta
1. En `card.php`: cambiar el elemento del botón add-to-cart de `<a href="?add-to-cart=...">` a `<button type="button">` con los mismos atributos `data-product_id`, `data-quantity`, `data-nonce`, y clases CSS existentes.
2. En `cart.js`: cambiar el event listener de `click` a `pointerup` para el botón add-to-cart:
   ```javascript
   $(document).on('pointerup', '.bsc__button-add-to-cart', function(e) {
       e.preventDefault();
       // evitar doble disparo
       if ( $(this).data('processing') ) return;
       $(this).data('processing', true);
       // ... lógica AJAX ...
       // limpiar flag en .always()
   });
   ```
3. Agregar guard `data-processing` para prevenir doble ejecución (click + touch simultáneos).
4. Mantener `aria-label` y accesibilidad en el `<button>`.
5. Verificar que el CSS del botón no cambia visualmente (solo el tag HTML).

## Qué NO se acepta como solución
- Mantener `<a>` con `href="?add-to-cart="` y solo agregar `touchstart`.
- Usar solo el evento `click` sin guard contra doble disparo.
- Modificar la lógica AJAX del handler PHP.

## Requerimientos
- El botón debe mantener su apariencia visual actual.
- No debe duplicar productos en el carrito al hacer tap.
- Debe mantener accesibilidad (`aria-label`, foco por teclado).

## Criterios de aceptación
- Add-to-cart funciona con un solo tap en iPad (iOS Safari y Chrome).
- No se agregan productos duplicados al carrito.
- El botón muestra feedback visual (loading state) durante la operación.
- Funciona igual en desktop con mouse.

## QA manual
- En iPad real o simulador iOS Safari: hacer tap en "¡Lo quiero!" → debe agregar al carrito una sola vez.
- Hacer tap rápido dos veces → no debe duplicar el producto.
- Verificar en Chrome DevTools con simulación de touch.
- Verificar con teclado: Tab hasta el botón → Enter → debe funcionar.
