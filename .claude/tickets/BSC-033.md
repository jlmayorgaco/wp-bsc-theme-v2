# BSC-033 — Campo de guía + cambio automático de estado + email de envío al cliente

## Objetivo
Cuando el operador agrega el número/link de guía de envío a un pedido, el sistema debe: guardar el tracking code y link, cambiar automáticamente el estado del pedido a "Enviado", y enviar un email automático bonito al cliente con el número de tracking y link.

## Contexto
El PDF pide este flujo explícitamente y NEW_FEATURES.md detalla los campos de tracking. Es un flujo crítico de operación: el operador solo debe agregar el tracking y el resto sucede automáticamente.

## Archivos a revisar
- `admin/bsc-orders-page.php` — inputs de tracking en la tabla de pedidos
- `admin/bsc-ajax-handlers.php` o nuevo archivo de handlers
- Nuevo `emails/bsc-order-shipped.php` — template del email de envío
- `inc/woocommerce.php` — hooks de cambio de estado para emails

## Implementación exacta
1. En el handler AJAX `bsc_save_tracking` (del BSC-031):
   - Guardar `_bsc_tracking_code` y `_bsc_tracking_link` en el post meta del pedido.
   - Cambiar el estado del pedido a `wc-shipped` automáticamente: `$order->update_status('shipped')`.
   - Disparar email: llamar la función de envío de email (ver paso 3).
2. Crear `emails/bsc-order-shipped.php` con el template HTML del email:
   - Asunto: "Tu pedido #{order_number} está en camino".
   - Contenido: nombre del cliente, número de pedido, código de tracking, link al tracking, datos de los productos comprados.
   - Diseño BSC (colores de la marca, logo).
3. Crear función `bsc_send_shipping_email($order_id)` en `inc/woocommerce.php` o nuevo helper:
   ```php
   function bsc_send_shipping_email($order_id) {
       $order = wc_get_order($order_id);
       if (!$order) return;
       $tracking_code = get_post_meta($order_id, '_bsc_tracking_code', true);
       $tracking_link = get_post_meta($order_id, '_bsc_tracking_link', true);
       $subject = 'Tu pedido #' . $order->get_order_number() . ' está en camino';
       ob_start();
       include get_template_directory() . '/emails/bsc-order-shipped.php';
       $message = ob_get_clean();
       wp_mail(
           $order->get_billing_email(),
           $subject,
           $message,
           ['Content-Type: text/html; charset=UTF-8']
       );
   }
   ```
4. Asegurarse de que el handler AJAX requiere nonce y capability `edit_orders`.

## Qué NO se acepta como solución
- Cambiar el estado sin enviar email.
- Enviar email sin cambiar el estado.
- Email sin el número de tracking y link.
- Handler AJAX sin nonce.

## Requerimientos
- Los tres pasos (guardar tracking, cambiar estado, enviar email) son atómicos: si uno falla, registrar el error en el log.
- El email tiene `Content-Type: text/html`.

## Criterios de aceptación
- Guardar tracking desde el admin → el estado cambia a "Enviado" automáticamente.
- El cliente recibe email con número de tracking y link.
- El email tiene diseño BSC reconocible.
- Si no hay email del cliente, registrar error sin romper la operación.

## QA manual
- Crear pedido de prueba → agregar tracking code y link desde el admin → guardar.
- Verificar que el estado del pedido cambió a "Enviado".
- Verificar que el email llegó a la bandeja del cliente de prueba.
- El email tiene el número de tracking y link funcionando.
