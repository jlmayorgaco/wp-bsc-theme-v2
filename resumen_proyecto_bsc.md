# Resumen del proyecto y del pedido del cliente

## Qué es el proyecto

Bubble Skin Care es una tienda e-commerce en WordPress + WooCommerce con una theme custom. El sitio no debe resolverse a punta de plugins ni page builders pesados; la lógica y la UI deben vivir dentro de la theme.

## Qué hace hoy el sitio

- Presenta un home altamente personalizado con hero, sliders, carruseles, marcas, favoritos, newsletter y footer custom.
- Tiene navegación desktop y mobile diferenciada.
- Usa WooCommerce para productos, carrito, cuenta y categorías.
- Tiene páginas o secciones especiales para marcas, skin care, cuenta, programas y contacto.

## Qué no debería hacerse

- No seguir agregando plugins sin auditar impacto.
- No meter parches rápidos sin revisar responsive.
- No dejar lógica funcional crítica escondida en JS frágil o hardcodes.
- No salir a producción sin QA en iPad y iPhone Safari.

## Problema central actual

El sitio tiene una combinación de:
- lentitud general,
- fallas funcionales,
- problemas responsive,
- enlaces incompletos,
- y menús / bloques que no están alineados con el diseño esperado del cliente.

## Qué pidió el cliente

El PDF se concentra en:
- performance,
- hero home,
- productos y carrito,
- tipos de piel,
- marcas,
- espaciados,
- footer,
- newsletter,
- WhatsApp,
- y rediseño del menú mobile.

## Prioridad real

1. Performance.
2. Carrito / add to cart / badge.
3. Marcas y navegación.
4. Menú mobile.
5. Links funcionales y QA final.
